# KeepKey Desktop Documentation

This directory contains documentation for the KeepKey Desktop application, covering various aspects of development, building, and troubleshooting.

## Windows Development Guides

Windows has some unique challenges when developing Electron applications with native dependencies. These guides provide detailed information on setting up, building, and troubleshooting KeepKey Desktop on Windows:

- [**Windows Build Guide**](windows-build-guide.md) - Overview of best practices for building on Windows
- [**Windows Environment Setup**](windows-environment-setup.md) - Step-by-step instructions for setting up a complete development environment
- [**Windows Troubleshooting**](windows-troubleshooting.md) - Solutions for common Windows-specific issues
